Who plays Horizon right now

Every running game sends an anonymous "I'm playing" ping once a minute: no account, no address, nothing you do in the game (what it holds). The count below is exact, and the server writes down only the totals each minute, so you can see the peaks over time.

Over time

Each point is the highest and the average count in its 5 minutes (24 hours), hour (7 days), 3 hours (30 days) or day (all, UTC days). Times are in your time zone. Minutes are kept 7 days, hours 90 days, days for good. The tabs set both charts on this page.

The official server

Horizon Official, the survival server (SMP) at the top of the game's server list. Every minute the telemetry server asks it how many play, with the same status ping your game's Multiplayer list sends; a gap in the line is a time it didn't answer.
